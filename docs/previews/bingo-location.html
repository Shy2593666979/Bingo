真正接入时，这些也一起做好
先确认，再发送
进入选择页不自动发消息。位置权限只在需要时申请；拒绝后仍可搜索地点。发送指定地点不等于用户人在那里，也不自动覆盖原来的「用户当前位置」。
卡片不靠截图识别
服务端保存独立的位置字段，本地数据库也保存。模型直接读取 JSON 文本，不需要识别地图截图。历史记录与伙伴详情都能还原位置卡片。
坐标与密钥分开处理
系统 GPS 坐标先转成高德 GCJ-02。Web 服务 Key 留在后端，不放 HTML、APK 或缩略图 URL；地图通过受鉴权接口读取。精确位置不默认写进长期记忆。
