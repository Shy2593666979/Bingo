# Bingo UI 方向预览

用浏览器打开同目录的 `bingo-ui-directions.html`。CSS、JS 和图片均为本地资源，整个目录保留即可离线查看。

## 五套方向

| 方案 | 配色与样式 | 适合的调整范围 |
| --- | --- | --- |
| A 薄荷留白 | 轻薄荷、柔和背景、清楚的动作层级 | 最接近现有品牌，优先推荐 |
| B 奶油杏桃 | 奶油色、杏桃重点色、轻边框 | 温暖自然的陪伴氛围 |
| C 雾紫轻社交 | 雾紫、大头像、胶囊按钮 | 更明显的年轻化，优先推荐 |
| D 云白蓝 | 云白蓝、紧凑字段、清晰边界 | 清爽、减少视觉负担 |
| E 午夜星光 | 蓝黑背景、浅星蓝重点色 | 可选夜间方向，不强制替换默认主题 |

## 使用方式

- 五套同屏：切换页面，对比相同场景下的不同设计。
- 单套体验：从登录、注册到资料、陪伴空间、聊天、创建伙伴等页面点击体验；配色和样式可独立混搭。
- 当前 APP 截图：查看模拟器实拍与简短分析，截图不包含模拟器外框。
- 共 27 个页面和状态。未触发的真实业务状态明确标为代码检查与布局演示，不代表已完成真实通话或声音复刻。
- 所有表单、录音、试听、聊天、删除及修改密码均为演示，不调用后端、不采集麦克风。默认伙伴编辑页的表单只用于比较视觉，实际功能权限继续以现有 APP 为准。
- 不改变现有伙伴卡片结构，不新增首页搜索、分类或排序入口。

参考项目及官方链接见 HTML 下方；参考的是组件层级、表单组织和主题体系，不复制其产品界面。

此目录为设计提案，不修改 Flutter 页面，不涉及部署或打包。
