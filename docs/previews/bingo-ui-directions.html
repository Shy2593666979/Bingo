先统一颜色

深绿保留给重点动作，普通进入、上传图片、次要选项用轻色。正文和辅助文字不再混用多种灰绿色。

再统一节奏

标题、字段、分组和底部动作有固定间距。个人资料去掉重复标题；登录协议不再挤到屏幕外。

最后优化状态

录音、复刻、错误、来电和接通状态统一设计。阶段进度不展示假百分比，未读数字不依赖颜色辨认。
