# 独立音色资产

角色与声音分开管理。`voices` 保存资产，`roles.voice_id` 保存角色默认选择，`role_preferences.voice_id` 保存用户为官方角色选择的声音，`voice_jobs.voice_id` 跟踪异步复刻。一个音色可以被多个角色使用，删除角色不删除音色。

## 数据与迁移

音色包含名称、描述、性别、可见范围（private/system/community）、所有者、供应商标识、处理状态和时间戳。供应商标识仅在服务端使用。用户只能修改自己的私有音色，系统和社区音色可试听与使用。

数据库初始化幂等新增列和索引，迁移系统、社区与历史私人音色，并保留旧角色声音字段兼容旧客户端。系统音色具有独立名称，不再用角色名作为列表标题；未添加对应角色也可选用。原角色代码及稳定 ID 不变。

## API（现有 API 前缀下）

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET / POST | `/voices` | 列表 / 新建独立资产 |
| PUT / DELETE | `/voices/{id}` | 修改 / 删除私人音色 |
| POST | `/voices/{id}/clone` | 提交同意授权后的录音复刻 |
| POST | `/voices/{id}/preview` | 试听资产 |
| PUT | `/roles/{id}/voice` | 为角色设置所选音色 |
| GET | `/voice-jobs/{id}` | 查询异步任务 |

新建音色不创建临时角色。任务有草稿、处理中、可用、失败状态；重复提交和重试关联已有资产。删除正在被角色或个人偏好使用的音色返回 409，先更换引用后再删除。删除原角色不影响复刻任务完成。账号删除负责清理私人资产及供应商资源。

官方角色的个人音色通过脱离会话的角色副本解析，不修改共享角色；创建偏好时保留原先的默认性格。单聊朗读、实时通话、群聊通话、群聊朗读及动态语音统一解析所选资产。

社区分享可以引用公共音色；私人音色不会因为发布角色而隐式公开。历史快照仍可读取。

## 客户端

我的音色 / 系统音色 / 社区音色独立分组，支持性别筛选、试听、新建、编辑、删除，以及明确选择一个搭子后应用。角色编辑页复用同一音色库。试听在切换、退页和应用进入后台时停止；忽略迟到的音频响应。

## 验证

`tests/test_voice_assets.py` 覆盖独立生命周期、权限隔离、官方角色个人选择、迁移幂等、旧数据库升级、系统音色完整性和社区复用。Flutter 的 `test/voice_library_test.dart` 覆盖无需角色的目录和创建、应用、迟到响应以及窄屏放大文字。云端 TTS 通过本地隔离 API 完成一次真实试听；真人录音复刻未在本轮手工执行。
