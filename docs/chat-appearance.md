# 聊天外观

聊天右上角的调色盘设置当前伙伴的外观；「我的 → 设置 → 聊天外观」设置全局默认外观。伙伴的「跟随全局」会移除独立配置，之后跟随全局变化；全局的「恢复默认」恢复薄荷日常，不覆盖伙伴的独立配置。

## 内置样式

选择页分为「插画款式 24」和「原创款式 11」。插画款式依据用户提供的两张商店截图，通过内置 ImageGen 生成透明 PNG，为近似还原，不是原始商店素材。

24 款依次为：胡萝卜啵啵、大狗狗是狼、啃骨小柴、小小航海家、一只姜小猫、桃子草莓奶、年兽小粉团、魔法幽灵、小熊甜品师、无敌萌萌ye、七七大王、尔尔冰淇凌、傻猫流口水、大运来咯、加热中、伤心社畜、求你了、桃花运、鼠大厨、星环遇二七、寒雪堡堡、秋雨小猫、无他、蘑菇豪。

插画资源位于 `apps/mobile/assets/chat_bubbles/`，生成提示词保存在 `docs/chat-bubble-image-prompts.json`。货车、锅的最终版本使用 `truck-v2.png`、`pot-v2.png`，初稿保留供对照。其他文件名与 `ref_` 样式 ID 对应。

「搭配」同时替换背景与气泡；「背景」「气泡」各自修改一项。上方实时预览使用实际聊天的壁纸和气泡组件。预览修改仅在点击保存后生效，返回不保存。

背景页支持系统相册选图、淡化、缩放和水平/垂直位置调整。图片使用 cover 铺满消息区，未缩放时可移动方向受图片比例限制。顶部栏和输入栏保留浅色底，时间标签有浅色衬底，消息气泡保持不透明，保证照片上的阅读体验。

## 实现与存储

- `lib/core/appearance/chat_appearance.dart`：样式目录、配置模型、账号外观状态、壁纸绘制和气泡容器。
- `lib/core/appearance/appearance_page.dart`：外观选择、预览、相册导入和照片调整。
- `lib/core/appearance/bubble_art.dart`：可随文字尺寸伸展的矢量皮肤，独立绘制兔耳、猫爪、蝴蝶结、花边、胶带及果冻高光。正文使用预留内边距，普通消息、通话记录、输入中气泡和缩略图共用同一套皮肤。
- `lib/core/appearance/raster_bubble.dart`：插画图片的九宫格绘制，按实际解码尺寸取样，伸展中部留白；预留正文边距、限制解码尺寸，维持人物和角落装饰的显示比例。长消息仍可能让贯穿整条边缘的局部插画产生一定伸展。
- `lib/core/appearance/reference_bubble_sizes.dart`：24 款最终 PNG 的原始尺寸。插画 ID 与旧版样式 ID 分开，未知 ID 仍回退薄荷日常。
- Android `ChatAppearanceStorage.kt`：后台任务队列中的本地偏好和私有壁纸文件操作，通道 `bingo/appearance`。
- 配置按用户 ID 隔离，伙伴覆盖项按稳定的伙伴 ID 保存，不依赖昵称或对话 ID。
- 图片复制到应用私有 `files/wallpapers/<账号哈希>/`，按内容哈希命名，不依赖相册临时权限或缓存目录。
- 保存时清理当前账号未被已保存配置引用的图片；注销账号时清理对应配置与壁纸。取消导入后的未引用文件会在下次保存或注销时清理。
- 保存成功后才通知聊天刷新；失败保留已应用的外观。切换外观不重新绑定会话，也不重置消息展示节奏或音频播放。
- 普通消息、正在输入、通话记录共用气泡装饰；位置卡片和闹钟卡片协调配色，功能结构保持清晰。
- 无新 Flutter 依赖，无服务端协议或数据库变更。偏好仅存本机，卸载或更换设备不会自动恢复。

## 验证

`test/chat_appearance_test.dart` 覆盖全局继承、伙伴覆盖、账号隔离、重建后恢复、保存失败保留旧设置，以及窄屏下所有气泡样式与预览草稿行为；320 像素宽、1.3 倍字号下检查全部皮肤的预览布局。关联检查包含聊天控制器、位置消息、闹钟卡片、输入栏、设置页和主题测试。
