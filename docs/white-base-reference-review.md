# 白底界面参考复审（2026-11-12）

本轮接用户对白熊白底层次感的新要求，替代此前 C 雾紫概念图作为主页面的视觉基准。实际产物见 `artifacts/white-base-preview/index.html`，包含首页、聊天、社区、我的和创建弹窗的真实 Android 截图与已有白熊参考图。

## 依据与边界

- 使用本机现有白熊 2.18.1 APK 的 Blutter 分析记录、`verified-ui-parameters.json`、对象池摘录与既有登录后实机截图。
- 本轮没有可调用的 REA 工具，也没有声称重新反编译或恢复原始 Dart 源码。当前模拟器未安装白熊，参考页面来自此前已采集的实际截图。
- 已核对主题字号层级、按功能分组的留白和页面结构；原截图与 APK 分析结论的出处记录在此前 `ui-whitebear-alignment.md` 和 `whitebear-structure-reference.md` 中。
- 参考截图只复制到本地评审产物，不加入 App 资源。Bingo 使用自己的头像、代码图标、数据和交互。

## 本次实现

- 主页面改为纯白 `#FFFFFF`，黑灰文字、`#FAFAFA` 功能区、`#F0F0F0` 细线；消除铺满页面的淡紫底和紫色边框。少量主要操作仍使用 Bingo 的紫色强调色。
- 首页保留 Bingo 自己的“创建、我的搭子、发现搭子、最近对话”结构，用中性灰卡片和更少的装饰建立层级。
- 社区参考白熊的创作者／好友／发布入口、描边搜索、分类、宽留白角色卡。卡片保留真实作者、添加、图片与标签。
- 我的页采用紧凑资料条、深色陪伴重点卡和浅灰分组菜单。重点卡显示真实搭子数量并进入搭子管理，不增加会员购买或虚假权益。
- 创建弹窗采用白底与灰色图标底。独立音色与七项人物属性、AI 开场白、后端逻辑均未改变。
- 保留最近确认的推荐预加载／交叉淡入、首页 13px 绿点与 1.5px 白边；聊天列表和聊天正文头像不显示在线点。
- 默认用户气泡 `#E7FECC`、描边 `#B7C4CA` 与在线状态 `#63BB68` 保留，系统字体保留。

## 验证

Flutter 全量 301 项通过，静态检查通过。修正了 320px 且文字放大 1.3 倍时社区顶栏的溢出。实际预览装在 `com.example.bingo.preview`，使用隔离的本地数据库。HTML 五个页面切换、图片加载与 390px 宽度检查通过。

没有修改公网服务、提交、推送、部署或重新生成 release 手机包。改版前文件快照在 `.tmp/pre-white-base-20261112/`，上一份手机 APK 仍保留。

## 后续修正：聊天名称与分享／详情

用户进一步明确：试用 15 号的是外层聊天列表的搭子／群聊名称；进入对话后的顶部标题继续 16 号。两处均保留 600 字重，群聊人数跟随列表名称字号。此前顶部改 15 的试验已恢复，旧对照图只作为历史记录。

分享页移除配图选择、缓存和提交逻辑；后端 `ShareCreate.images` 仅接受省略或空列表，带配图的新分享返回 422，角色头像不受影响。历史分享的图片读取保留。该后端调整尚未部署公网。
