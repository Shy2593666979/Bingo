## 图片问题

用户已明确：社区发布自己的搭子时，不允许附带额外图片；搭子头像保留。发布表单没有选图入口，提交不携带配图，服务端拒绝非空 `images`。创建搭子的头像入口、系统选图、裁剪与回显继续保留；模拟器实际完成了该头像流程，未保存/发布角色。
