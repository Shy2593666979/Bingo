# 聊天信息页

聊天页右上角「…」进入独立页面，保留返回、伙伴头像与昵称、语音通话入口。聊天信息使用灰色页面、白色分组和细分隔线。

- 查找聊天记录：搜索当前会话的服务端消息，最多显示 100 条匹配结果；支持打开完整消息。输入防抖，忽略过期搜索响应。
- 消息免打扰：服务端按会话保存；新主动消息不入推送队列，已排队的消息在发送前再次检查。聊天消息仍保留，来电和用户创建的约定提醒不受此开关影响。
- 置顶聊天：服务端按会话保存；伙伴列表优先显示置顶伙伴，同组内保留本地拖动顺序。
- 自动朗读：复用已有账号级朗读偏好，关闭时停止当前朗读。
- 背景与气泡：分别打开现有外观页的对应标签，保存、取消和伙伴独立设置规则不变。
- 陪伴记录：打开当前会话的专注、约定、小记与入睡记录。
- 清空聊天记录：二次确认后删除当前会话消息及相关主动消息、推送、记忆提取检查点和设备操作；保留伙伴、外观、已保存记忆及陪伴记录。回复或通话进行中拒绝清空。取消待执行的旧轮次跟进，清空客户端消息缓存。

## 接口

- `GET /api/v1/conversations/{id}/settings`
- `PATCH /api/v1/conversations/{id}/settings`，可分别传 `muted`、`pinned`
- `GET /api/v1/conversations/{id}/messages?q=关键词&limit=100`
- `DELETE /api/v1/conversations/{id}/messages`

接口均校验会话归属。SQLite 启动升级增加 `conversations.muted` 和 `conversations.pinned` 两列，默认关闭。客户端功能需要配套更新服务端；无需新增 Flutter 依赖。

## 验证

`apps/mobile/test/chat_info_page_test.dart` 覆盖开关保存失败、清空确认、异步搜索结果顺序、背景标签入口与置顶排序。聊天控制器测试验证新抬头、通话和设置内朗读操作。

`apps/server/tests/test_chat_info.py` 覆盖设置隔离与持久化、关键词搜索、只清空当前会话、保留记忆、跨账号拒绝、回复中禁止清空，以及免打扰对新推送和排队推送的抑制。
