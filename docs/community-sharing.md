# 搭子社区与客户端导航

以 [新版视觉标准](designs/README.md) 为准。主导航为首页、聊天、社区、我的；中央加号进入创建中心，提供创建搭子、创建群聊、分享搭子。

## 页面与交互

首页显示创建搭子、创建群聊、发现社区三个快捷入口，下面为我的搭子和自己创建的群聊。角色使用实际头像及圆角方形容器。聊天入口统一使用导航栏同款三点气泡图标。

社区包含推荐、最新、热门、搜索、分类、热门前三与分享动态。更多菜单进入我的收藏、我的发布和分享。热门区独立查询全站排行，不随搜索词和分类改变。查看更多切换热门列表。卡片展示真实头像、介绍、标签和互动数量。

热门排序为点赞数 + 收藏数 + 未删除评论数降序；平分按分享时间从新到旧，再以 ID 稳定排序。加入次数不参与排序。热门区最多三位，不填充虚构角色或互动数。

分享详情展示实际角色大图、作者、标签、介绍、人设、展示图片和评论。只有“加入我的搭子”这一主操作，加入成功后变为“开始聊天”。编辑自己的副本在更多菜单中。没有试聊、预览会话、公开群聊或加入他人群聊入口。群聊只由用户用自己的搭子创建。

群聊不展示单独的 @ 按钮。只有输入框光标前正在输入 @ 查询时，在输入框上方展示匹配搭子列表；选择后写入正文并关闭候选，不生成额外标签。发送前核验正文仍包含被选中的 @ 名称。

## 复制与分享

- 发布保存当前人设的不可变快照，原角色之后修改不影响已发布分享。
- 加入创建新的 Role ID 与自己的 RolePreference，复制名称、头像、人设、描述、身份、性格、分类、标签和允许公开的系统音色。
- 原作者的聊天、记忆、账号数据和私人复刻音色不复制；私人音色替换为系统音色。
- 重复加入返回同一仍存在的副本，删除后可重新加入。并发请求不会保留多个副本。
- 同名冲突追加数字；副本可以独立编辑、再次分享，并保留来源关系。
- 撤回分享禁止新增查看和加入，其他用户已有副本继续保留。
- 点赞、收藏使用显式布尔状态，重复请求不重复计数；评论使用 request_id 去重。
- 评论作者和分享作者可以删除评论。删除评论不再贡献热度。
- 注销清理用户的分享、点赞、收藏、评论、安装映射与举报，其他用户已有的独立副本保留。

## 接口

接口位于 `/api/v1` 并要求登录。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/community/characters` | q、scope、sort、offset、limit 查询 |
| POST | `/community/characters` | role_id、introduction、request_id、images 发布 |
| GET | `/community/characters/{id}` | 详情与公开人设 |
| GET | `/community/characters/{id}/avatar` | 独立头像 |
| GET | `/community/characters/{id}/images/{index}` | 展示图片 |
| POST | `/community/characters/{id}/install` | 加入自己的搭子 |
| PUT | `/community/characters/{id}/favorite` | 收藏状态 |
| PUT | `/community/characters/{id}/like` | 点赞状态 |
| GET | `/community/characters/{id}/comments` | 评论分页 |
| POST | `/community/characters/{id}/comments` | 内容与去重 request_id |
| DELETE | `/community/characters/{id}/comments/{comment_id}` | 删除自己的评论或自己分享下的评论 |
| DELETE | `/community/characters/{id}` | 作者撤回分享 |
| POST | `/community/characters/{id}/reports` | 举报 |

旧 `/preview` 接口已移除。新增 `character_likes`、`character_comments` 表由启动建表流程创建。列表延迟加载头像、人设和图片原文，避免将 Base64 带进分页数据。

## 验证

服务端完整测试 313 项通过；客户端完整测试 186 项通过，Flutter analyze 无问题。覆盖热度三项求和、时间排序、加入不影响热门、评论重试去重、删除权限、撤回、试聊接口移除、窄屏与大字体、重复加入、独立副本聊天与 @ 候选交互。

模拟器使用隔离的 `.tmp/appearance-qa.db` 与本地服务，已验证真实互动、加入后聊天、键盘弹出后的 @ 候选与选中效果。未向正式服务发布测试内容。截图见 新版实机预览（开发预览已清理）。
