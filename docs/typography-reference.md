# 系统字体与文字层级（2026-11-07）

2026-11-08 补充：主题 getter 不等于每个页面组件的实际字号。本轮根据实机控件边界，将主要页面顶部和默认 AppBar 调整为 18/w600；聊天列表保留 15/w500，个人菜单使用 15/w600。当前布局以 `whitebear-structure-reference.md` 为准，后文早期的“保留 Bingo 原布局”已被本轮结构对照取代。

本轮依据本机白熊 2.18.1 的 ARM64 Blutter 输出及 1080×2400、density 480 的模拟器截图。没有可调用的 REA 接口；使用已有反编译产物继续追踪组件调用，未声称取得原始 Dart 源码。未引入第三方素材或字体。

## 核实结果

| 用途 | 参数 | 静态证据 |
| --- | --- | --- |
| 主题大标题 getter | 22 / w500 | `BearDesignTokens::headingLarge`，0x1b8eb20 |
| 主题中标题 getter | 18 / w500 | `BearDesignTokens::headingMedium`，0x1cd167c |
| 普通聊天列表名称 | 15 / w500 | `_ChatItemViewState::build`，0x1ad1f30；继承 tokens.field_2b |
| 官方助手名称 | 15 / w600 | `OfficialAccountListTile::build`，0x1d86740；覆写 tokens.field_2b |
| 个人页菜单 | 15 / w600 | `MePageContent::_buildSettingItem`，0x1c11f44、0x1c1216c |
| 个人页名称 | 16 / w500 | `me_view.dart`，0x1d91938 |
| 正文层级 | 18、15、14 / w400 | `BearDesignTokens::fromPalette`，0x1d5380c～0x1d53888 |
| 时间及辅助文字 | 12 / w400 | tokens.field_3b，0x1d538a8；聊天列表时间使用此字段 |

FontWeight 对象池核对：1fcf491=600、1fcf4a1=500、1fcf4b1=400。fromPalette 中的 field_2b 对应 15/w500，field_33 对应 15/w400，field_37 对应 14/w400，field_3b 对应 12/w400。

因此不能从主题 getter 的 w500 推断所有页面标题均为 w500。菜单与官方名称在组件层覆写为 w600。

## Bingo 的对应实现

统一入口 `BingoTypography`，使用系统字体，不设置额外字体族：

- 页面标题 22/w500，分区标题 18/w600。
- 列表名称 15/w500，菜单和卡片强调名称 15/w600，个人名称 16/w500。
- 正文 15/w400，说明 14/w400，时间和辅助信息 12/w400。
- 字距明确设为 0，避免继承 Material 3 中不同角色的默认字距。
- 行高按 Bingo 的内容和窄屏适配设为 1.3～1.5；这是适配选择，不宣称已从白熊每个页面还原相同行高。

五个主页面接入这些语义样式。消息列表头像调整为 48、上下内边距 12；个人菜单最小行高 56，与较小字号共同建立层级，保留可点击区域。Bingo 自有功能、配色、头像和布局结构继续保留。

白熊没有 Bingo 的同构首页和社区分享卡，因此分区标题、社区作者/卡片/正文的映射属于本项目适配，不是假称逐控件复制。聊天正文继续保持 16/w400，以实际气泡换行验证。

第一轮把名称与菜单统一压到 w500 已被本轮按用途区分取代。测试、截图和模拟器运行记录以本次实际执行结果为准。

## 默认聊天外观补充

单聊顶部使用独立居中的名称与状态，两侧控件不会挤偏标题；顶部右侧头像已按反馈移除，名称继续支持详情点击、长按插入名字。消息头像保留原有交互。查找记录仍在聊天信息页。状态根据当前控制器显示在线、正在输入或连接异常，未额外实现独立在线检测。

默认 mint 气泡以代码绘制白底/浅绿底、浅灰细描边及左右小尾巴，不复制第三方气泡 PNG。按实机反馈进一步收紧：水平内边距至少 14，普通消息上下内边距 8，最大宽度为屏宽 72%（上限 480）。默认背景为纯白，已有其他外观继续走其原有渲染分支。普通默认消息下方显示本地时间，头像对齐气泡底部。系统字体正文 16/w400，行高 1.35，字距 0。

此补充执行了 66 项聊天相关测试与静态检查，并覆盖安装到已登录模拟器查看已有单聊。没有发送额外测试消息；用户侧短消息和其他皮肤由现有渲染测试覆盖。
