## 音色能力边界

后端已新增 `voices` 表。角色使用 `voice_id` 引用，官方角色的个人选择保存在用户偏好中。旧字段保留用于兼容；新页面直接操作音色资产，不再通过创建角色来创建音色。详见 `voice-assets.md`。

系统音色不要求先添加对应搭子。音色有独立名称、描述、性别、范围和处理状态；删除角色不删除其音色。正在被引用的音色不能直接删除，需先更换引用。

试听使用现有原生播放器，切换试听、打开资料或离开页面时停止播放。迟到的异步音频结果不能在离开页面后播放。

## 视觉规则

使用系统默认字体、白底、黑灰文字、浅灰分组与细分隔线。主要操作使用玫粉色，选中反馈使用浅粉白；导航和普通功能图标仍以黑灰为主。根据用户进一步反馈，默认用户气泡固定保留上一版浅绿色 `#E7FECC`，描边保留 `#B7C4CA`，与应用强调色独立，单聊和群聊共用；在线文字和指示点同样保留绿色。移除旧薄荷渐变与硬编码选中背景。保留 Bingo 自有头像和导航功能，以及用户自行选择的插画皮肤。整套页面的视觉方案仍待用户确认。

本地使用独立包 `com.example.bingo.preview` 和隔离数据库验证，不覆盖原应用或公网数据。后端全量 472 项、Flutter 全量 301 项测试通过；之后的性格保留与登录页收尾由相关测试复验。独立音色接口已返回真实云端 TTS 音频，复刻任务生命周期由自动化测试覆盖，本轮未上传新的真人录音。未提交、推送或部署。
