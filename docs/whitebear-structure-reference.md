# 白熊结构对照（2026-11-08）

本轮以白熊 2.18.1 的本机截图、1080×2400 / density 480 的控件边界和已有 ARM64 Blutter 索引为参照。不是重新设计一套相近风格。没有新运行 REA，也没有声称恢复原始 Dart 源码。

## 页面与尺寸

| 页面 | 原图结构与基准 | Bingo 实现 |
| --- | --- | --- |
| 发现 | 56 高标题区，60 高入口行，行间距 8 | 首页改为相同的入口列表，接社区、陪伴空间、外观、音色、聊天和创建 |
| 聊天 | 56 高顶部、居中标题、72 高会话行、48 头像；无常驻筛选栏 | 搜索与筛选保留在搜索展开状态，置顶、长按操作、未读和创建菜单继续可用 |
| 广场 | 左右边距 20；40 高入口与搜索，分类胶囊、最新/最热；白底大圆角角色卡 | 创作者入口管理分享与收藏；好友进入搭子管理；卡片进入详情，添加、点赞、收藏和评论仍在详情可用 |
| 个人 | 左右边距 16；欢迎卡顶端 y=100、高 165；菜单从 y=285 开始，普通行高 54 | 移除原统计区，恢复黑色米金卡片、紧凑菜单；卡片按钮进入真实的搭子管理，数量放在对应菜单右侧 |
| 音色 | 84 高浅粉提示卡；两个主标签、筛选、粉白列表卡、56 封面、底部使用按钮 | 我的 / 系统两个主标签；社区音色从“音色来源”菜单切换，独立音色数据模型保持不变 |
| 创建 | 创建方式弹窗与五步表单 | 七个人物属性分为基本信息、说话风格、性格标签、人物背景、人物声音五步；保留步骤校验和返回内容 |
| 导航 | 白底细顶线，58 高，黑灰图标 | 保留 Bingo 的首页、聊天、创建、社区、我的入口，采用相同高度与图标层级 |

尺寸单位为逻辑像素。聊天行原图边界 `y=240..456` 对应 72；个人卡片 `x=48..1032, y=300..795` 对应左右 16、高 165。页面标题采用 18/w600 匹配实机组件，不直接套用主题大标题 getter 的 22。

## 功能适配

- 白熊没有与 Bingo 完全同构的首页。现有搭子预览、推荐换一换、添加和最近聊天保留在首页的“陪伴空间”入口，未删除。
- 白熊会员卡的购买功能在 Bingo 没有对应能力，保留卡片布局，按钮接搭子管理，没有增加虚假付费入口。
- 创建仍使用约定的七项属性，没有新增角色性别或固定开场白。AI 开场白和后端群聊逻辑未改动。
- 用户默认气泡固定 `#E7FECC`、描边 `#B7C4CA`，在线文字和在线指示点固定 `#63BB68`，不跟随强调色变化。
- 使用项目自身角色头像和代码生成的装饰；没有把白熊的角色、商店、糖果或会员素材打包进 App。音色封面为本项目按音色 ID 生成的流体纹理。

## 验证与运行范围

Flutter 全量 301 项测试通过；实机校准后的聊天、社区、个人页面相关 14 项测试复验通过。静态检查通过。分步创建测试覆盖空名称阻止前进、五步推进、返回后背景保留、独立音色选择与保存。

使用 `com.example.bingo.preview` 的独立本地预览包和隔离数据库；未改后端、未提交、未推送、未部署。原公网安装包和用户数据保持原状。
