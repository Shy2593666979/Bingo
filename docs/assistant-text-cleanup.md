# AI 回复连续破折号清理

规则只作用于 AI 聊天输出，不修改用户原话、工具参数或长期记忆。

- 句子内连续中文破折号转换为逗号，已有标点前后、段落开头或末尾直接移除。
- 仅包含连续破折号或三个以上 ASCII 短横线的独立分隔行删除，不生成空的聊天气泡。
- 单个破折号、日期、负数、正常短横线及数字区间保留；网址中的连续破折号也保留。
- 流式输出只暂存可能跨分片的破折号和末尾空白，不等待完整回答，不添加固定延迟。
- 正常聊天、流式聊天、语音朗读、主动回访和早安消息均在展示和存储之前清理。短期上下文中的旧助手消息也清理，但不批量修改原有历史记录。
- 模型若只输出分隔符，返回无有效回复提示，不保存空的助手消息。

实现：`apps/server/bingo/utils/assistant_text.py`。测试包含分片边界、用户内容保护、历史一致性和朗读输入一致性。
