## 声音与隐私说明

视频使用昵称为“小田”的独立演示账号和新生成的合成音源，不使用手机所有者的声音或此前提供的个人录音。演示音源由电脑扬声器播放，手机麦克风真实录入，再交由应用调用云端复刻、语音识别或实时通话服务。它展示的是合成演示音源的复刻流程，不声称录制了真人朗读。通话演示发言略微加快、减少句中停顿，并在 AI 说完后再开口。

由于手机内部声音录制不包含麦克风输入，用户一侧的原始演示发言按录制时记录的实际播放时间同步混入音轨；不是随意添加的旁白。AI 试听、聊天回复与通话回复均采集于实际播放过程，不事后生成替代音轨。通话音频经轻度降噪，成片统一响度。

早期模拟器录制未完成复刻与双向通话，原有两段不完整 MP4 已替换为此次真机流程；不将失败录制剪辑成成功结果。视频仅含演示资料，未使用其他应用画面或个人聊天记录。
