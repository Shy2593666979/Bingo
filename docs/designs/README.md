# Bingo 新版视觉标准

本轮以用户提供的 `多面板AI陪伴应用界面设计.png` 为主标准，原图保存为 [product-standard.png](product-standard.png)。

使用内置 imagegen，根据原图生成了 [community-detail-v2.png](community-detail-v2.png)，用于明确社区与搭子详情的布局、留白、圆角和配色。核心提示词：沿用参考图的浅薄荷白、淡紫粉横幅与圆角方形角色头像；社区包含分类、热门三个真实角色卡、用户发布动态；详情包含角色大图、作者、介绍、人设、相册与评论，唯一主操作为“加入我的搭子”；不得出现公开群聊、加入别人的群、试聊、预览对话。

实现时卡片和详情使用实际角色头像、用户上传图片与服务端数据。生成图仅作为视觉参考及横幅装饰，标题、按钮和交互均由原生组件实现。

热门搭子按点赞数 + 收藏数 + 未删除评论数排序，平分时按分享时间从新到旧，首页仅展示前三。加入人数不参与热门排序。加入后得到独立角色 ID，可以聊天、编辑和再次分享。

App 图标使用用户提供的 `bingo-logo.png`，通过 flutter_launcher_icons 生成 Android 标准及自适应图标。
